## Sobre mí

Estudio Desarrollo de Aplicaciones Multiplataforma y me estoy especializando en backend y cloud: Java, arquitecturas serverless y servicios de AWS. Hice prácticas como programador full stack en Qraneos (mayo - junio de 2026), donde desarrollé una aplicación de control de asistencia con autenticación Microsoft OAuth usando TypeScript, Prisma y Vite. Antes trabajé en remoto como probador de software en Lionbridge (2024 - 2025).

Fuera de las clases construyo proyectos propios para aprender haciendo: aplicaciones web, una extensión de navegador y juegos.
